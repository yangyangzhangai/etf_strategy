# 代码架构与系统边界

## 1. 产品边界

本阶段只有一条数据链路：`公开数据源 → 标准化 → 缓存/质量标记 → API → 人类可读看板`。

评分和预测作为未来独立模块存在，不能反向污染数据层：

```text
新浪 / 腾讯 / 同花顺 / 交易所 / 东方财富 / mootdx / 人工文件
        ↓
Provider 适配层 ── 只处理字段、类型、代码补零
        ↓
Gateway 韧性层 ── TTL、互斥、重试、陈旧缓存、示例降级
        ↓
SQLite 数据层 ── 数据集缓存、ETF 份额日快照
        ↓
Service 领域层 ── 市场统计、ETF 原始指标、可追溯元数据
        ↓
FastAPI 契约层 ── 只读 JSON API
        ↓
React 看板 ── 核心数字常驻、分类摘要、点击展开
```

未来的 `scoring/` 和 `forecasting/` 只能消费已经版本化的标准化数据，不允许直接调用 AKShare，也不允许覆盖原始值。

## 2. 分层职责

### Provider 适配层

- `FreeEtfProvider`：组合新浪全 A/ETF 行情与 ETF 日线、腾讯行情备用、同花顺行业/净值和交易所份额；市场与 ETF 默认主源。
- `AkshareProvider`：东方财富全 A/行业主源及 ETF 备用源。
- `AktoolsProvider`：可选 HTTP 适配器，用于把独立 AKTools 服务纳入相同契约。
- `MootdxProvider`：只提供自选 ETF 行情与未复权日线备用；自动尝试多个通达信节点。
- `ImportService`：校验 xlsx/csv 后持久化为最后一道真实数据兜底。
- `SampleProvider`：离线开发和测试使用，响应必须标为 `sample`。
- 所有证券代码统一为六位字符串，所有时间统一输出 ISO 8601。
- Provider 不计算 RSI、回撤等领域指标。

### Gateway 韧性层

- 同一数据集只允许一个并发刷新，避免请求风暴。
- ETF 优先级：新鲜缓存 → 免费组合源 → 东方财富 → AKTools → mootdx → 人工导入 → 陈旧缓存 → 示例数据（仅 auto 模式）。
- 市场优先级：新鲜缓存 → 新浪/腾讯+同花顺 → 东方财富 → AKTools → 陈旧缓存 → 示例数据（仅 auto 模式）。
- 任何降级均写入 `meta.status` 和 `meta.message`，前端不得隐藏。
- 不在用户请求中循环抓取数千只个股历史数据。

### Service 领域层

- 市场服务只做全 A 截面统计和行业原始数据整理。
- ETF 服务负责价格历史、回撤、RSI、波动率、ATR、均线偏离和相对收益等可解释指标。
- 指标公式必须无前视数据，字段命名带周期，例如 `realizedVolatility20Pct`。
- 所有“分位”均同时返回原值、样本数和观察区间。

### API 契约层

- API 版本固定为 `/api/v1`。
- 失败时优先返回带质量说明的可用缓存，不返回伪造的实时状态。
- V1 不提供 `/score`、`/signal`、`/forecast` 和交易写接口。

### 前端展示层

- 第一屏只保留市场原始摘要、ETF 核心指标和数据质量。
- 分类区域只展示关键数字和一句解释；`details` 展开后显示完整原始值。
- 颜色只表达涨跌或数据质量，不表达“买入/卖出”。
- 数据缺失显示 `—` 和原因，禁止用 0 替代未知。

## 3. 数据新鲜度

| 数据集 | 默认 TTL | 原因 |
|---|---:|---|
| 全 A 实时行情 | 5 分钟 | 控制东财请求频率，同时支持盘中观察 |
| ETF 实时行情 | 5 分钟 | 与全 A 保持一致 |
| 行业板块 | 15 分钟 | 变化频率低于个股行情 |
| ETF 日线 | 6 小时 | 日频数据，收盘后更新即可 |
| ETF 份额快照 | 每交易日一条 | 用本系统自身积累 1/5/20 日变化 |

## 4. 已知限制

- 东方财富可能限流、变更字段或增加验证，AKShare 也可能随之失效。
- `stock_zh_a_spot_em()` 是截面数据，无法直接得到 MA20/60/120 市场宽度；该能力需要后续逐日历史底座，不能通过盘中高并发临时抓取实现。
- ETF 内部市场宽度需要指数成分股和点时成分权重，本阶段只保留数据契约和“尚未接入”状态。
- ETF 份额变化从系统首次采集之日起积累，历史不足时显示缺失原因。
- 新浪与 mootdx 日线未复权；来源和降级原因必须显示，发生除权事件时需另行校正连续价格口径。
- 免费主链不稳定提供 IOPV；单位净值不得冒充盘中 IOPV，缺失时保持为空。
- 本系统不是交易所行情终端，不适合逐笔、盘口或自动交易。
