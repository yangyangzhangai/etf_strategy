# 代码规范

## 通用规则

- 源代码、API 字段、数据库字段使用英文；用户界面与业务文档使用中文。
- 金额在 API 中使用元，百分比使用百分数口径（`-2.5` 表示 `-2.5%`），字段名或数据字典必须写明。
- 证券代码永远是字符串，禁止转为整数。
- 未知值使用 `null`，禁止以 `0`、空字符串或 `NaN` 冒充。
- 所有外部数据都携带 `source/status/asOf/message`。

## Python

- Python 3.11+，采用 `ruff`、类型标注和 pytest。
- Provider 返回标准 Python 记录；服务层不得依赖 DataFrame 列名。
- 外部调用必须有超时、有限重试和缓存回退。
- 指标函数保持纯函数，同一输入必须得到同一输出。
- 捕获异常时必须保留根因到日志/元数据，不允许裸 `except: pass`。

## TypeScript / React

- 开启 strict；外部 JSON 先经过类型边界再进入组件。
- 页面只组合数据与交互，格式化函数放入 `lib/`。
- 不在组件中实现指标公式，不在浏览器中纠正后端数据。
- 可展开模块使用原生语义或完整键盘操作；所有状态色同时配文字。
- 禁止用虚构分数填充尚未实施的评分模块。

## Git 与评审

- 单次提交只解决一个可描述问题。
- 修改数据字段时同时更新数据字典、类型和测试。
- 修改指标公式时必须写明旧/新版本，不静默覆盖历史结果。
- PR 必须说明：数据来源、缺失处理、缓存策略、用户可见变化和验证结果。
