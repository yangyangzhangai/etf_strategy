## M2：分类评分（暂不启动）

进入条件：M1 数据字段、方向、缺失率和跨标的稳定性通过验收。

- 指标去相关和信息族分组。
- 每张分类卡独立公式、方向和解释。
- 样本外稳定性验证。
- 禁止在 M2 之前出现综合买入分或阈值信号。

## M3：历史统计与预测（暂不启动）

进入条件：评分指标版本冻结，历史数据满足逐时点可复原。

- 可选 3/5/10/15/20 交易日持有期。
- 正收益概率、Expected Value、MFE/MAE、置信区间。
- Historical Twin 与有效样本数。
- Opportunity Ranking 仅比较当下 Risk/Reward。

## 第一版验收标准

1. 后端在无网络时可用明确标记的示例数据启动。
2. AKShare 请求失败时不会无限重试，也不会把示例数据标成实时。
3. 每个看板区块能看到来源、更新时间和质量状态。
4. 核心数值不需要点击；详细原始值通过展开区域查看。
5. 代码中不存在评分、预测、交易命令或收益承诺。
6. 后端单元测试和前端生产构建通过。
